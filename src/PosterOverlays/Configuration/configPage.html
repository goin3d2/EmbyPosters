    Data sources

    Used for series status. Without it, Emby's own Continuing/Ended status is used (no Airing or Canceled).
    IMDb publishes every title's rating as one daily download for personal, non-commercial use. It's fetched at most once a day.
    Needed only for Rotten Tomatoes (and for IMDb if you pick MDBList above). If no Rotten Tomatoes badge is ticked, MDBList is never called.
    Each run checks how many calls your MDBList account has left today and uses all but this many, so other tools sharing the key (Kometa, Seerr, list syncs) still have room. Titles with no ratings yet are fetched first, newest first; the rest are picked up on later runs.
    Optional. Limits a single run even when the account has more left, to spread calls across the day's four runs.
